# Healer Recap

Public website for WoW Mythic+ run reviews and guild information.

This repository contains only the browser-facing website, assets and published report data. Internal combat-log analysis, review methodology and private evidence are maintained separately and are not part of this public source repository.

Before publishing, run `node scripts/check-public-safety.js`. Raw logs, credentials, prompts, scoring rules, parser internals, private evidence and admin data must remain outside this repository. See `SECURITY.md` for the public/private boundary.
