ABOUT M+ RECAP

Understand the run, then improve the next one.

M+ Recap turns recorded Mythic+ combat events into clear run summaries, death recaps and practical review points. It separates recorded facts from interpretation and uses confidence language where a log cannot establish the full context.

Current stage

The site is being developed as a Cause and Effect guild beta. Public character dashboards use deliberately published run reports and Blizzard profile information. Uploads, private reports and automatic reviews will move to an authenticated backend as the project develops.
