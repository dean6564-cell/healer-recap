PRIVACY

How information is currently used

Last updated 5 September 2026

Published information

This public beta displays selected World of Warcraft character, guild and run information. Published reports can include character names, realms, party activity, combat events and review conclusions.

Browser storage

The site can store character selection and local report preferences in your browser. This information remains on that device unless a future authenticated service states otherwise.

Uploads and local imports

Authorised beta members can submit combat logs through the separately authenticated upload service. Raw logs and account-linked queue records are stored privately in EU-restricted Cloudflare storage and are not added to the public repository. Processed report files imported locally remain in that browser. Only a finished report deliberately selected for publication appears on this website.

Corrections and removal

Use the contact page to report incorrect information or request review of published data. Do not post sensitive information in a public GitHub issue.
